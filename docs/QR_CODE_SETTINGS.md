# QR Code Settings Documentation

## Актуално състояние - QR кодове за маси

### Общо описание
Страницата за управление на QR кодове (`/bg/admin/qr`) позволява на администраторите да генерират и персонализират QR кодове за всяка маса в заведението. Всички настройки се запазват в `localStorage` и се прилагат автоматично при генериране/регенериране на QR кодовете.

---

## Структура на настройките

### Панел с настройки - Grid Layout

Панелът с настройки е организиран в grid с 4 колони на desktop (`md:grid-cols-4`) и 1 колона на mobile (`grid-cols-1`).

#### Row 1: Цветове (3 колони)
1. **Цвят на фона** (`backgroundColor`)
   - Тип: Color picker + text input
   - По подразбиране: `#FFFFFF`
   - Описание: Цвят на фона на QR картата

2. **Цвят на QR кода** (`qrCodeColor`)
   - Тип: Color picker + text input
   - По подразбиране: `#000000`
   - Описание: Цвят на самия QR код

3. **Цвят на буквите** (`textColor`)
   - Тип: Color picker + text input
   - По подразбиране: `#000000`
   - Описание: Цвят на всички текстове в картата

#### Row 2: Размери и отстояния (4 колони)
1. **Размер на QR кода (px)** (`qrCodeSize`)
   - Тип: Number input
   - Обхват: 200-800px
   - Стъпка: 50px
   - По подразбиране: `400`
   - Описание: Размер на QR кода в пиксели

2. **Отстояние на QR кода (px)** (`qrCodeMargin`)
   - Тип: Number input
   - Обхват: -100 до 100px
   - Стъпка: 1px
   - По подразбиране: `0`
   - Описание: Margin на QR кода (позволява отрицателни стойности за придвижване)

3. **Размер на текста (px)** (`scanTextSize`)
   - Тип: Number input
   - Обхват: 10-50px
   - Стъпка: 1px
   - По подразбиране: `20`
   - Описание: Размер на шрифта на текста за сканиране

4. **Отстояние на текста (px)** (`scanTextMargin`)
   - Тип: Number input
   - Обхват: -50 до 50px
   - Стъпка: 1px
   - По подразбиране: `0`
   - Описание: Margin на текста за сканиране (позволява отрицателни стойности)

#### Row 3: Ориентация (full width - 4 колони)
- **Ориентация на картата** (`orientation`)
  - Тип: Radio buttons
  - Опции:
    - `portrait` - Портретна (продълговата / вертикална)
    - `landscape` - Ландшафтна (широка / хоризонтална)
  - По подразбиране: `portrait`
  - Описание: Определя разположението на елементите в QR картата

#### Row 4: Размери на табелката (3 колони: ширина | празно | височина)
1. **Ширина на табелката (cm)** (`cardWidth`)
   - Тип: Number input
   - Обхват: 5-20cm
   - Стъпка: 0.5cm
   - По подразбиране: `8.5`
   - Описание: Ширина на QR картата в сантиметри (използва се при принтиране и PDF)

2. **(Празно място)**

3. **Височина на табелката (cm)** (`cardHeight`)
   - Тип: Number input
   - Обхват: 3-15cm
   - Стъпка: 0.5cm
   - По подразбиране: `5.5`
   - Описание: Височина на QR картата в сантиметри (използва се при принтиране и PDF)

#### Row 5: Текст за сканиране - Български (full width - 4 колони)
- **Текст за сканиране (Български)** (`scanTextBg`)
  - Тип: Text input
  - По подразбиране: `"Сканирай за меню и поръчка"`
  - Описание: Българският текст, който се показва под QR кода

#### Row 6: Текст за сканиране - English (full width - 4 колони)
- **Текст за сканиране (English)** (`scanTextEn`)
  - Тип: Text input
  - По подразбиране: `"Scan for menu & order"`
  - Описание: Английският текст, който се показва под QR кода

#### Row 7: Лого или текст (full width - 4 колони)
- **Лого или текст** (`useLogo`)
  - Тип: Radio buttons
  - Опции:
    - `false` - Текст
    - `true` - Лого (изображение)
  - По подразбиране: `false`

##### Ако е избран "Текст":
- **Текст за лого** (`logoText`)
  - Тип: Textarea (3 реда)
  - По подразбиране: `"𝐋.𝐔.𝐍.𝐀 🌙\nBar & Coffee - Русе"`
  - Описание: Текст, който се показва вместо лого (поддържа нови редове с Enter)

##### Ако е избран "Лого (изображение)":
- **URL на лого** (`logoUrl`)
  - Тип: Text input
  - По подразбиране: `""`
  - Описание: Пълен URL или относителен път към изображението (напр. `https://example.com/logo.png` или `/logo.png`)
  - Бележка: Показва preview на логото с фона от настройките

- **Размер на логото (px)** (`logoSize`)
  - Тип: Number input
  - Обхват: 40-800px
  - Стъпка: 10px
  - По подразбиране: `80`
  - Описание: Ширина на логото в пиксели (височината се запазва автоматично за запазване на съотношението)

- **Отстояние на логото (px)** (`logoMargin`)
  - Тип: Number input
  - Обхват: -100 до 100px
  - Стъпка: 1px
  - По подразбиране: `0`
  - Описание: Margin на логото (позволява отрицателни стойности)

## Структура на QR картата

### Портретна ориентация (portrait)

```
┌─────────────────────────┐
│      [LOGO/TEXT]        │  (центрирано)
│                         │
│      [QR CODE]          │  (центрирано, с margin)
│                         │
│  ─────────────────────  │  (бяла линия)
│  [📱] Текст за          │  (икона + текст, центрирано)
│      сканиране          │
│                         │
└─────────────────────────┘
```

**Елементи:**
1. Лого/Текст (отгоре, центрирано)
2. QR код (в центъра, с настройваемо отстояние)
3. Бяла линия (разделител)
4. Икона на смартфон + текст за сканиране (отдолу, центрирано)

**Икона:**
- Файл: `/smartphone_10450488.png`
- Размер: `4rem x 5rem` (64px x 80px)
- Позиция: Вляво от текста, вертикално центрирано

### Ландшафтна ориентация (landscape)

```
┌─────────────────────────────────────────┐
│  [QR CODE]  │  [LOGO/TEXT]              │
│             │                           │
│             │                           │
│             │  ─────────────────────    │
│             │  [📱] Текст за            │
│             │      сканиране            │
└─────────────────────────────────────────┘
```

**Елементи:**
1. QR код (вляво, с настройваемо отстояние)
2. Лого/Текст (вдясно отгоре, с настройваемо отстояние)
3. Бяла линия (разделител, отдолу)
4. Икона на смартфон + текст за сканиране (вдясно отдолу)

**Flexbox layout:**
- QR код: `flex-shrink-0`
- Десен панел: `flex-1 flex flex-col`
  - Лого/Текст: горе
  - Текст за сканиране: абсолютно позициониран отдолу

## Стилизация

### Текст за сканиране

**Структура:**
```jsx
<div className="border-t-2" style={{ paddingTop: '0.025rem', ... }}>
  <div className="flex items-center gap-3">
    <img src="/smartphone_10450488.png" style={{ width: '4rem', height: '5rem' }} />
    <div>
      <p style={{ fontSize: `${scanTextSize}px`, ... }}>{scanTextBg}</p>
      <p style={{ fontSize: `${scanTextSize}px`, ... }}>{scanTextEn}</p>
    </div>
  </div>
</div>
```

**Стилове:**
- `paddingTop: '0.025rem'` - Много малко разстояние между бялата линия и текста
- `items-center` - Вертикално центриране на иконата и текста
- `gap-3` - Разстояние между иконата и текста
- Размер на текста: настройваем чрез `scanTextSize`

### Бяла линия (разделител)

**Стилове:**
- `border-t-2` - Топ border с дебелина 2px
- Цвят: 
  - Тъмен фон (`#000000` или `#000`): `#374151` (сиво)
  - Светъл фон: `#cbd5e1` (светло сиво)

## Функционалности

### Генериране на QR кодове

1. **Първо генериране:**
   - Бутон: "✨ Генерирай"
   - Генерира QR кодове за всички 30 маси
   - Използва текущите настройки от панела

2. **Регенериране:**
   - Бутон: "🔄 Регенерирай"
   - Показва модално прозорче за потвърждение
   - Презаписва всички съществуващи QR кодове

### Изтегляне на PDF

- Бутон: "⬇️ Изтегли PDF"
- Използва библиотеките `html2canvas` и `jspdf`
- Генерира PDF с всички QR карти
- Размер на страниците: според `cardWidth` и `cardHeight` (конвертирани в mm)
- Центриране на картите на всяка страница

### Принтиране

- Бутон: "🖨️ Принтирай"
- Отваря нативния браузър диалог за принтиране
- Print CSS скрива всички не-QR елементи
- Прилага настройките за размер, цвят и ориентация

## LocalStorage

Всички настройки се запазват автоматично в `localStorage` с ключ `qrCodeSettings`.

**Формат:**
```json
{
  "backgroundColor": "#FFFFFF",
  "textColor": "#000000",
  "qrCodeColor": "#000000",
  "qrCodeSize": 400,
  "qrCodeMargin": 0,
  "orientation": "portrait",
  "useLogo": false,
  "logoText": "𝐋.𝐔.𝐍.𝐀 🌙\nBar & Coffee - Русе",
  "logoUrl": "",
  "logoSize": 80,
  "logoMargin": 0,
  "scanTextBg": "Сканирай за меню и поръчка",
  "scanTextEn": "Scan for menu & order",
  "scanTextSize": 20,
  "scanTextMargin": 0,
  "cardWidth": 8.5,
  "cardHeight": 5.5
}
```

## API Endpoints

### `PUT /api/qr/generate`

Генерира или регенерира QR кодове за всички маси.

**Request Body:**
```json
{
  "settings": {
    "backgroundColor": "#FFFFFF",
    "textColor": "#000000",
    "qrCodeColor": "#000000",
    "qrCodeSize": 400
  }
}
```

**Response:**
```json
{
  "success": true,
  "message": "QR codes generated successfully",
  "tables": [
    {
      "tableNumber": 1,
      "qrCodeDataUrl": "data:image/png;base64,..."
    },
    ...
  ]
}
```

## Технически детайли

### Икона на смартфон

- **Файл:** `/public/smartphone_10450488.png`
- **Middleware:** Файлът е изключен от локалната обработка в `middleware.ts`:
  ```typescript
  '/((?!api|_next/static|_next/image|favicon.ico|uploads|t|manifest.*\.json|sw\.js|luna-icon|luna-logo|smartphone.*\.png).*)'
  ```
- **Размер:** `4rem x 5rem` (64px x 80px)
- **Object fit:** `contain` (запазва съотношението)

### Print CSS

Print стиловете се прилагат чрез `@media print` и включват:
- Скриване на всички не-QR елементи (`visibility: hidden`)
- Показване само на `.qr-card` и неговите деца
- Прилагане на `print-color-adjust: exact` за запазване на цветовете
- Размер на страниците според ориентацията (A4 portrait/landscape)
- `overflow: hidden` за отрязване на излизащи елементи

### PDF Generation

- Използва `html2canvas` за капсулиране на HTML като изображение
- Използва `jspdf` за създаване на PDF документ
- Размер на изображенията: според `cardWidth` и `cardHeight` (конвертирани в mm)
- Центриране: `x = (pageWidth - cardWidth) / 2`, `y = (pageHeight - cardHeight) / 2`
